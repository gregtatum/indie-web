# Privacy Policy and Usage

{{SITE_DESCRIPTION}}

## Definitions

**The Site:** {{SITE_DISPLAY_NAME}} at [{{SITE_URL}}]({{SITE_URL}})<br/>
**User:** A user of The Site.

## What stays local

When you use local browser storage, files never leave your device.

## What syncs

Remote stores like Dropbox sync files to your account. This enables access from
multiple devices.

## Dropbox

The Site can use a Dropbox account to access files. The Site does not store
Dropbox user information beyond the authorization tokens provided by Dropbox.
[Dropbox has its own privacy policy.](https://dropbox.com/privacy) The Site
only requests access to a scoped app folder, and not the broader Dropbox
files. The information about the files and folders are only stored in the
User's browser through the localStorage and IndexedDB APIs.

Information about the User's Dropbox account and the User's files and folders
are *not* stored nor collected by The Site.

## Netlify

The front-end application is hosted through Netlify which has its own
[privacy policy](https://www.netlify.com/privacy/).

## Guarantees

are free to use the service, but Greg Tatum provides no guarantees and
assumes no responsibility for the usage of the app or the integrity of the
data that is stored in the website or stored in third party services, such
as Dropbox.

Please report any bugs for data integrity on
