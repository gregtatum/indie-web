# Getting started

## Connect your files

Start at the [connection page](/connect) and choose where you want to keep your files:

* [Browser](/docs/file-store-browser.html) — keep everything in this browser.
* [Dropbox](/docs/file-store-dropbox.html) — work with files stored in Dropbox.
* [Local & network storage](/docs/file-store-server.html) — work directly with folders on your computer or NAS.

## Try something

Once you're connected, here are a few ways to explore:

* **Write something.** Create a Markdown file and start typing. You can preview the formatted document as you work and paste or drag images directly into it.
* **Chart a song.** Create a [ChordPro file](/docs/chordpro.html), add some chords, then try transposing it or switching to Nashville or Roman numerals.
* **Build a music library.** Drop in some [sheet music, PDFs, or images](/docs/pdfs-and-images.html) and organize them into folders.
* **Practice along.** Add an MP3 to a song and play it alongside your chord chart.
* **Start a project.** Make a folder for some writing, notes, research, images, or whatever else you're working on. They all live together as ordinary files.

## Add and organize files

Use the add button to create files and folders, or drag existing files from your desktop into the app.
